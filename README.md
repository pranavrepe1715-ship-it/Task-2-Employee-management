# Task 2 — CRUD Employee Management System

Node.js, Express, and MySQL employee management API with a frontend page.

## Setup
1. Install Node.js and MySQL.
2. Create a database and import `database/schema.sql` (check the SQL file for database/table names).
3. Copy `.env.example` to `.env` and set your local database credentials and JWT secret.
4. Run `npm install`, then `npm start`.
5. Open `http://localhost:3000/employees.html`.

Note: employee routes use JWT authentication middleware. Run the Authentication System task as well or provide a valid token as required by the route.

## GitHub
Create a separate repository named `WeIntern-Employee-Management` and upload the contents of this folder. Do not commit `.env`.
